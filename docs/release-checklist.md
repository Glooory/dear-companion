# Release Acceptance Checklist

此清单用于每一个候选版本。自动化通过只证明核心逻辑、静态检查、构建和非视觉启动没有已知失败；它不证明界面、安装器、系统集成或性能正确。

## Agent 可验证项目

在候选版本对应的干净提交上运行并记录命令、日期和提交 SHA：

```bash
npm install
npm run icons:generate
npm run release:validate-tag -- vX.Y.Z
npm test
npm run lint
npm run typecheck
npm run build
DEAR_COMPANION_BUILD_SMOKE=1 npx electron out/main/index.js
```

- [ ] 核心单测通过，且没有 UI、React、快照、Playwright 或 E2E 测试。
- [ ] lint、typecheck 与生产构建通过。
- [ ] 非视觉 Electron 启动冒烟退出码为 0；未打开或操作窗口。
- [ ] 工作树不包含 `release/`、`out/`、日志、设置、凭据或用户导入的图片/音频。
- [ ] 标签精确等于 `v${package.json.version}`。

## 功能验收 — 等待用户验证

- [ ] `等待用户验证`：首次安装没有提醒；开机启动和所有声音均关闭。
- [ ] `等待用户验证`：创建和删除伙伴；导入用户已抠好的透明 PNG/WebP，归一化高度、缩放、偏移与地面基准线正确且原始副本不变，删除一个伙伴不会影响其他伙伴。
- [ ] `等待用户验证`：全身微动作（轻呼吸、换重心、踮脚、伸懒腰、探身等）与照片平滑交叉淡化转场符合预期；头部热区往返移动触发摸头，非热区触发推动。
- [ ] `等待用户验证`：生活状态（日常陪伴、困倦、睡觉与工作）切换正常；睡觉状态下连续点击三次逐步唤醒；工作时段自动触发与右键手动切换正常。
- [ ] `等待用户验证`：单击/双击竞争、悬停倾斜、普通拖动、快速拖动抗议、位置重启恢复与多显示器边缘回退正常。
- [ ] `等待用户验证`：透明置顶窗口与透明区域鼠标穿透（click-through）正常；设置单例与页签切换正常；托盘显示/隐藏/退出与图标正常。
- [ ] `等待用户验证`：对白自定义与称呼替换（`[称呼]`）正常；内置对白启停与修改、新增台词正常；右键常用对白快捷呼出正常。
- [ ] `等待用户验证`：对白配音 8 秒录音、波形裁剪、导入音频与音画同步正常；独立配音开关与音量生效。
- [ ] `等待用户验证`：创建、编辑、启停、删除提醒；固定时间点与时段内按间隔重复（分段间隔）触发正常；5/10/15 分钟延后正常。
- [ ] `等待用户验证`：独立气泡窗口（Bubble Window）位置自适应与主题色继承正常；休息倒计时基于绝对结束时间稳定走动。
- [ ] `等待用户验证`：休息期间鼠标移动超过容差触发轻柔哭闹督促；持续移动顺延哭闹，手停约 3 秒后自然恢复，不增加或打乱总倒计时。
- [ ] `等待用户验证`：手动结束、睡眠/唤醒、时区或系统时间变化不会补弹错过提醒或重复触发。
- [ ] `等待用户验证`：内置/导入 MP3、WAV、OGG、WebM、M4A 音频，独立声音开关，播放时长上限与播放失败静默回退正常。
- [ ] `等待用户验证`：隐藏伙伴在提醒时临时显示，提醒/休息结束后恢复用户持久化的可见性。
- [ ] `等待用户验证`：首次伙伴渲染崩溃自动重建；连续失败进入托盘/设置安全模式；显式重试可恢复。
- [ ] `等待用户验证`：安装后的开机启动可启用和关闭，重启/登录后状态一致；开发 Electron 从未注册为启动项。
- [ ] `等待用户验证`：单屏、多屏、负坐标、断开显示器和不同缩放比例下行为正确。
- [ ] `等待用户验证`：断网运行所有功能正常；平台网络监视工具未观察到生产应用发起远程请求。

## 性能记录 — 等待用户验证

每个平台使用 Task Manager 或 Activity Monitor。启动应用、配置一个代表性伙伴后静置至少 5 分钟再记录待机数据；随后执行 2 分钟代表性单击、拖动、提醒和休息活动并记录活动数据。记录三次采样的范围或平均值，不使用瞬时单点结论。

## 发布批准 — 等待用户验证

- [ ] `等待用户验证`：三种产物、校验值、安装指引和版本说明均已人工核对。
- [ ] `等待用户验证`：所有未通过项目已有明确说明、处理决定和负责人。
- [ ] `等待用户验证`：GitHub Release 仍为草稿，直到维护者完成上述验收后手动公开。
