# Dear Companion 伙伴对白配音与设置层级设计

日期：2026-09-04

## 1. 目标与范围

本设计在现有“对白与称呼”功能上增加按句保存的本地配音，并将伙伴设置改为“形象与动作”和“对白与称呼”两个二级页签。对白页不再使用独立嵌套编辑页，而是直接显示称呼和声音总控、五个生活场景页签，以及当前场景内展开的对白编辑卡片。

本功能保持完全离线。录音、导入音频、配音关联和音量设置只保存在本机，不上传、不记录原始文件路径，也不引入任何网络服务。

本次包含：

- 每句内置或用户对白可选绑定一个本地声音。
- 麦克风录音最长 8 秒，完成后可试听、重录或使用。
- 支持导入 MP3、WAV、OGG、WebM 和 M4A，单个文件最多 5 MB。
- 对白气泡出现后约 80 ms 起播对应声音；新对白会让旧声音在约 50 ms 内淡出，气泡关闭时停止声音。
- 用户可为每个伙伴分别开关对白声音并设置音量；默认关闭，默认音量为 80%。

本次不包含声音剪辑、变声、降噪、波形编辑、自动配音、AI 生成声音或云同步。

## 2. 信息架构

当前伙伴详情页顶部显示两个二级页签：

- `形象与动作`：伙伴名称、显示高度、陪伴节奏、照片、生活场景和动作。
- `对白与称呼`：称呼、对白声音总控、场景对白和按句配音。

对白页顶部是称呼和声音总控，中部是“平时陪伴”、“有点困了”、“睡觉”、“专注陪伴”和“其他互动”五个场景页签（仅保留场景名称，不附加静态时机计数）；卡片标题保留互动时机名称与三态批量启用复选框，完整对白清单直接在卡片内展开。

当前场景中的每个互动时机直接显示完整对白清单，不再进入第三层编辑页。场景页签和伙伴二级页签都使用标准 tab 语义，键盘可到达并公布当前选中状态。

窄窗口中，单句编辑器分为两行：第一行保留启用复选框和对白输入，第二行显示配音、来源、恢复和删除操作。

## 3. 配音交互

未配音时显示带添加图标的 `声音` 按钮。已配音时显示包含 `▶ 试听`、`更换` 和 `删除` 的操作胶囊（音频文件不可用时呈现 `声音不可用` 状态），不冗余标注“已配音”文本。行内试听和录音试听使用当前对白音量。

录音弹窗的状态为：

1. `准备录音`：可开始录音或从电脑选择音频。
2. `正在请求权限`：防止重复点击，可关闭弹窗并安全取消后续处理。
3. `录音中`：显示剩余时间和具有进度语义的环形指示，可提前停止，8 秒后自动停止。
4. `录音完成`：可试听、重新录制或“使用这段录音”。
5. `保存中`：防止重复提交和关闭，失败后保留录音并给出重试入口。

弹窗打开后将焦点移入，限制 Tab 焦点在弹窗内，Escape 可在非保存状态关闭，关闭后焦点返回原按钮。错误使用 `role="alert"`，状态和整秒倒计使用一个低频原子状态区域，不在 100 ms 进度刷新时反复播报。

录音或导入成功后，页面明确提示“尚未保存”。只有外层“保存设置”成功后，新配音才成为持久配置。

## 4. 数据与迁移

设置 schema 升级为 V6。V5 迁移为 V6 时：

- `voiceEnabled` 默认为 `false`。
- `voiceVolume` 默认为 `0.8`。
- 所有对白默认没有 `voiceAssetId`。

数据结构为：

```ts
interface PetDialogueSettings {
  address: string;
  voiceEnabled: boolean;
  voiceVolume: number;
  categories: Partial<Record<DialogueCategory, DialogueCategorySettings>>;
}

interface BuiltInDialogueOverride {
  lineId: string;
  automaticEnabled?: boolean;
  text?: string;
  voiceAssetId?: string;
}

interface CustomDialogueLine {
  id: string;
  automaticEnabled: boolean;
  text: string;
  voiceAssetId?: string;
}
```

声音 ID 只能引用当前伙伴 `voices/` 目录中已验证的文件。对白选择保留稳定行 ID，不通过最终文字反向查找配音。最终文字重复时仍只保留一句，并使用对应保留条目的声音。

“恢复原句”只恢复文字，保留启用状态和已绑定声音。“恢复内置对白”恢复该时机所有内置文字并重新启用，保留已绑定声音和用户对白。

## 5. 本地文件与原子保存

每个伙伴的声音保存在 `<userData>/pets/<petId>/voices/`。伙伴 ID、声音 ID 和扩展名分别使用白名单验证；读取时使用 canonical path 再次确认文件仍在当前伙伴的声音目录内。

主进程对文件内容而不是用户文件名进行格式检测，并尝试解码。格式、解码或体积校验失败时不写入文件。音频只作为数据读取，不执行元数据或其他内容。

新配音先以待确认文件保存。更换或删除操作只改变渲染器草稿，不立即删除当前持久文件。保存伙伴设置时，主进程按以下顺序处理：

1. 验证新配置中的每个声音引用属于当前伙伴。
2. 原子写入新配置。
3. 删除已不再被配置引用的旧声音和待确认声音。

如果配置保存失败，原配置和原声音保持可用，新声音保留为待确认草稿，便于用户重试。设置窗口关闭或切换伙伴时，主进程清理未被任何持久配置引用的待确认声音。

删除伙伴时先将伙伴目录改名到待删除目录，再原子更新配置。最终删除失败时记录待重试目录，应用本次启动后和下次启动时继续尝试，不把残留文件误报为已完全清理。日志不记录原始导入路径。

## 6. 权限与进程边界

Preload 只暴露录音保存、本地声音选择、草稿清理和伙伴更新所需的类型化方法，不暴露通用 IPC、文件系统、shell 或命令执行。所有写入和删除 IPC 必须校验发送方是设置窗口，并在主进程重新校验 payload。

麦克风权限只在以下条件同时满足时允许：

- 发起者是设置窗口的主框架。
- 生产环境来源为 `app://renderer`，开发环境来源严格匹配当前开发源。
- Electron 权限类型为 `media`，请求媒体类型仅为 `audio`。

其他所有权限请求继续默认拒绝。macOS 安装包在 `Info.plist` 中提供直接、具体的麦克风用途说明。

## 7. 播放时序与资源释放

对白选择结果同时包含稳定行 ID、最终文字和可选声音 ID。播放协调器一次只管理一个延迟计时器和一个正在播放的 `Audio`。

- 新对白到来时取消上一个尚未起播的计时器。
- 旧声音在约 50 ms 内淡出，然后执行 `pause()` 并清空 `src`。
- 气泡超时关闭、显式清除、伙伴切换和页面卸载都停止声音。
- `play()` 失败、`error` 或 `ended` 都清理引用和事件处理。
- 录音弹窗在重新录制、关闭、错误或卸载时停止试听、撤销 object URL、停止所有媒体 tracks 并取消计时器。

播放失败不影响气泡和伙伴动作。设置页对无法解析、缺失或无法播放的已绑定声音显示“声音不可用”，并提供更换或删除入口。

## 8. 视觉、文案与可访问性

界面延续当前温和、克制的浅色风格，使用现有 4/8 px 间距节奏和语义色彩。正文与小字在所在背景上至少达到 4.5:1，有含义的边界和图标至少达到 3:1。

录音中只动画进度环和一个低干扰脉冲；启用 `prefers-reduced-motion: reduce` 时取消脉冲和缩放。按钮 hover 和 pressed 状态不改变布局边界。禁用状态同时使用原生 `disabled` 语义和明显的弱化外观。

用户可见文案直接表达当前状态和后果：

- 新建时使用“添加对白声音”，替换时使用“更换对白声音”。
- 录音确认按钮使用“使用这段录音”，不使用可被误解为已持久化的“确认使用”。
- 导入说明完整列出 MP3、WAV、OGG、WebM 和 M4A，以及 5 MB 上限。
- 不使用“点击下方”、“在左侧选择”等位置说明，不使用营销套话或客服腔。

## 9. 错误恢复

- 麦克风权限被拒绝：停止已取得的任何 track，说明如何在系统设置中重新允许，并保留本地文件导入入口。
- 录音器初始化或开始失败：停止所有 track，恢复到可重试状态。
- 导入失败：区分格式、解码、空文件和超过 5 MB，不显示原始路径。
- 配置保存失败：保留草稿和新录音，原设置与原声音保持不变。
- 声音播放失败：继续显示气泡，设置页显示可恢复的不可用状态。

## 10. 测试与验收

自动化测试只覆盖必要核心逻辑和可复用共享方法：

- V5 到 V6 迁移与新配置严格解析。
- 音频格式、大小、解码结果和安全标识符校验。
- 待确认声音的保存、替换、失败回滚、未引用清理和伙伴删除。
- 权限决策只允许设置窗口的麦克风请求。
- 对白候选结果保留稳定行 ID 和对应声音。
- 播放协调器的 80 ms 起播、50 ms 淡出、超时停止和资源释放。

不添加 UI 单元测试、React 组件测试、快照测试、浏览器测试或自动化端到端测试。完成时执行允许的完整单元测试、lint、类型检查、生产构建和非视觉 Electron 启动冒烟检查。

以下项目等待用户在 Windows 和 macOS 手动验证：

- 二级页签、五个场景和展开卡片的层级与扫读效率。
- 常用与窄窗口宽度下的对白行排版和横向滚动提示。
- 录音授权、拒绝、重新授权、倒计、提前停止、试听和重录。
- 录音、替换、删除和保存失败后的用户反馈和焦点返回。
- 对白气泡与声音的实际起播同步、连续点击淡出和气泡关闭静音。
- 当前浅色主题中文字、图标、边界、hover、focus 和禁用状态的对比度。

## 11. 完成标准

- 新老安装的 V5 设置可迁移到 V6，默认不播放对白声音。
- 麦克风权限只授予设置窗口的音频输入请求，其他权限继续拒绝。
- 导入或录制的内容在主进程通过格式、解码、体积和路径校验。
- 未保存、替换、删除、恢复、保存失败和伙伴删除都不会留下无法追踪的声音或损坏已持久配置。
- 一次只播放一句配音，气泡关闭和页面卸载后没有声音、计时器、MediaStream track 或 object URL 残留。
- 二级页签和场景页签具有正确语义，录音弹窗符合标准模态焦点行为，小尺寸图标不再是关键操作的唯一入口。
- 所有用户可见文案直接、克制、无位置废话，并准确区分“使用录音”与“保存设置”。
