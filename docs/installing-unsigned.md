# 安装未签名的 挚伴

挚伴安装包尚未购买 Windows 代码签名证书，也未使用 Apple Developer ID 签名或公证。请只使用项目维护者提供的安装包，并先核对发布页中的 SHA-256 校验值。

不要关闭系统安全功能，也不要批量或递归移除其他文件的隔离属性。

## Windows 10/11 x64

1. 下载与发布说明相符的 Windows x64 安装包并核对 SHA-256。
2. 双击安装包。若 Microsoft Defender SmartScreen 显示“Windows 已保护你的电脑”，确认发布来源可信后选择“更多信息”。
3. 检查应用名为 挚伴，再选择“仍要运行”。
4. 按安装向导完成当前用户安装。首次启动后，开机启动和所有声音均保持关闭，除非用户在设置中明确开启。

如果警告内容、文件名或校验值与发布说明不一致，请取消安装。

## macOS 13+（Intel 或 Apple Silicon）

1. 下载与 Mac 架构匹配的 DMG 并核对 SHA-256。
2. 打开 DMG，将 挚伴 拖入“应用程序”（`/Applications`）。
3. 首次打开时，macOS Gatekeeper 通常会提示“‘挚伴.app’已损坏，无法打开。你应该将它移到废纸篓。”（这是 macOS 针对未签名下载应用的隔离机制，系统设置中通常不会出现“仍要打开”按钮）。
4. 打开“终端”（Terminal），运行以下命令移除对该应用的隔离标记：
   ```bash
   xattr -cr /Applications/挚伴.app
   ```
5. 完成后即可正常双击打开 挚伴。后续启动无需重复此操作。

## 卸载

- Windows：从“设置 → 应用”卸载 挚伴。
- macOS：退出应用后，将“应用程序”中的 挚伴 移到废纸篓。
