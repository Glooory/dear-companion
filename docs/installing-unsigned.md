# 安装未签名的 挚伴

挚伴 第一版仅面向家人和少量朋友分发，安装包尚未购买 Windows 代码签名证书，也未使用 Apple Developer ID 签名或公证。请只使用项目维护者提供的安装包，并先核对发布页中的 SHA-256 校验值。

不要关闭系统安全功能，也不要批量或递归移除其他文件的隔离属性。

## Windows 10/11 x64

1. 下载与发布说明相符的 Windows x64 安装包并核对 SHA-256。
2. 双击安装包。若 Microsoft Defender SmartScreen 显示“Windows 已保护你的电脑”，确认发布来源可信后选择“更多信息”。
3. 检查应用名为 挚伴，再选择“仍要运行”。
4. 按安装向导完成当前用户安装。首次启动后，开机启动和所有声音均保持关闭，除非用户在设置中明确开启。

如果警告内容、文件名或校验值与发布说明不一致，请取消安装并联系维护者。

## macOS 13+（Intel 或 Apple Silicon）

1. 下载与 Mac 架构匹配的 DMG 并核对 SHA-256。
2. 打开 DMG，将 挚伴 拖入“应用程序”。
3. 在 Finder 的“应用程序”中按住 Control 点击 挚伴，选择“打开”，然后在确认框中再次选择“打开”。
4. 如果仍被阻止，打开“系统设置 → 隐私与安全性”，在明确确认应用来源可信后使用针对 挚伴 的“仍要打开”。

不要关闭 Gatekeeper，也不要对“应用程序”目录执行递归 `xattr` 命令。若系统提示与本文不同，请停止并记录系统版本与提示内容。

## 卸载

- Windows：从“设置 → 应用”卸载 挚伴。
- macOS：退出应用后，将“应用程序”中的 挚伴 移到废纸篓。

卸载程序是否保留本地宠物图片、音频和设置，需要在每个平台发布验收时明确记录；不要在未备份私人素材前手动删除应用数据目录。
