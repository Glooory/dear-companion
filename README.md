# 挚伴 (Dear Companion)

挚伴（Dear Companion）是一款私密、离线的桌面照片伙伴。你可以把自己准备好的透明背景人物或宠物照片导入应用，配置为平时陪伴、有点困了、打盹睡觉和陪伴工作等生活状态，通过桌面伙伴获得轻量互动与定时休息提醒。

项目使用 Electron、React、TypeScript 和 Vite 构建，面向 Windows 10/11 x64，以及运行 macOS 13 或更高版本的 Intel 与 Apple Silicon Mac。


## 主要功能

- **照片导入与非破坏性微调**：导入用户已处理好透明背景的 PNG 或 WebP 图片。自动分析透明边界并统一可见高度和地面基准线，缩放、偏移等微调仅保存为非破坏性元数据，不修改原始文件。
- **多伙伴管理与快速切换**：支持添加多个独立伙伴包，设置 80–260 px 显示高度，在设置窗口或托盘菜单中随时切换当前伙伴。
- **全身照片生命感体系**：采用“真人照片 × 轻度卡通物理”动作语言。人物保持全身比例，具有自然的间歇轻呼吸、换重心、踮脚、探身观察或分步小位移；照片状态切换采用平滑短交叉淡化（Cross-fade）。
- **多样化鼠标互动**：鼠标悬停时轻微倾斜靠近；支持为每张照片设置椭圆头部热区并触发往返摸头；支持平滑拖动与快速拖动生气抗议；睡觉状态下支持连续点击三次逐步唤醒。
- **多种生活状态与工作计划**：支持平时陪伴（可在安静、自然、活泼节奏间选择）、有点困了、打盹睡觉和陪伴工作等生活状态；可创建多个本地工作时段（支持跨午夜），或随时通过右键菜单手动切换状态。
- **智能气泡对白与主人称呼**：按生活场景与互动事件分类（如被点、被摸头、自主活动、困倦、叫醒、工作、提醒督促等）；支持自定义主人称呼（`[称呼]`）；可查看、修改、停用、恢复内置对白并添加自定义台词。
- **本地对白配音与波形裁剪**：可为每句对白录制最长 8 秒的麦克风声音，并提供可视化音频波形裁剪器精确调整起止时间；亦可导入 MP3、WAV、OGG、WebM 或 M4A 短音频；对白配音配有独立总开关与音量控制。
- **常用对白快捷呼出**：可为伙伴挑选最多三句非休息对白作为“常用对白”，通过桌面伙伴右键菜单随时呼出展示，并在配音开启时播放声音。
- **灵活的休息提醒计划**：支持“固定时间点”与“时段内按间隔重复（最多 3 个时段）”两种模式；提醒到点后通过气泡邀请用户立即休息或延后 5、10、15 分钟。
- **独立气泡窗口与防沉迷督促**：采用独立的置顶透明气泡窗口（Bubble Window），自动适应台词长度并继承伙伴主题色；休息期间稳定显示剩余倒计时与结束按钮；检测鼠标移动并在超限时触发轻柔哭闹督促（持续移动顺延哭闹，手停约 3 秒后自然恢复，不增加或打乱总休息倒计时）。
- **声音与隐私安全**：提醒音、哭闹督促音与对白配音独立控制，支持内置声音与本地音频（MP3、WAV、OGG），默认全部关闭；应用完全离线运行，零远程请求，零遥测，不记录原始文件路径，严格保护私人照片与音频。
- **完整的设置中心与内置使用指南**：提供伙伴管理、行为与状态、自定义对白、声音与提醒，以及图文兼备的“使用指南”页签。
- **托盘控制与异常自愈**：支持托盘菜单快速控制、伙伴位置多屏安全恢复、渲染崩溃单次自愈与安全模式。

首次安装不会自动创建提醒，也不会自动开启声音或开机启动。

## 隐私与安全

挚伴 的生产版本完全离线：

- 图片、音频、伙伴配置、提醒和设置只保存在本机 Electron `userData` 目录。
- 不包含账号、云服务、遥测、更新检查、远程脚本或依赖网络的素材。
- 不保存或记录导入文件的原始路径和内容；应用使用随机生成的内部名称保存本地副本。
- 摸头候选期间的鼠标轨迹只短暂存在于内存中，不持久化、不写入日志，也不会通过 preload 暴露通用鼠标监听能力。
- 原始导入副本保持不变，裁切、缩放、偏移和对齐均通过元数据完成。
- Renderer 不直接访问 Node.js、Electron、文件系统或 shell，只能调用 preload 暴露的窄类型 API。
- 生产环境阻止远程 HTTP、HTTPS、WebSocket 请求和非预期权限请求。

图片单文件上限为 20 MiB、尺寸上限为 8192 × 8192，每个伙伴包上限为 250 MiB。普通音频单文件上限为 20 MiB，最多播放前 30 秒。对白录音上限为 8 秒，导入对白音频上限为 5 MiB。

## 本地开发

### 环境要求

- Node.js 24
- npm（Node.js 自带）

项目已默认配置国内镜像加速（`.npmrc`）。

#### 方式一：Windows 小白一键启动（推荐）

- 双击根目录下的 **`1-启动开发模式.bat`** 即可自动安装依赖并启动开发环境。
- 双击根目录下的 **`2-打包生成安装包.bat`** 即可自动构建打包，完成后在 `release/` 目录获取安装程序。

#### 方式二：命令行启动

安装依赖并启动开发环境：

```bash
npm install
npm run dev
```

运行项目允许的自动化检查：

```bash
npm test
npm run lint
npm run typecheck
npm run build
```

运行非视觉 Electron 启动冒烟：

```bash
DEAR_COMPANION_BUILD_SMOKE=1 npx electron out/main/index.js
```

自动化测试仅覆盖必要的核心状态、计算、迁移、恢复和输入验证。UI、React 组件、快照、Playwright 与 E2E 测试不属于本仓库的测试范围；界面和操作系统行为由用户人工验收。

## 构建与打包

构建当前平台的未打包应用或安装包：

```bash
npm run package:dir
npm run dist
```

这两个命令都不会发布 Release。产物写入 `release/`，且不应提交到仓库。

GitHub Actions 的 tag 发布流程会分别构建：

- Windows x64 NSIS 安装程序
- macOS Intel DMG
- macOS Apple Silicon DMG

流程要求 tag 与 `package.json` 版本完全一致，生成 SHA-256 校验文件，并创建或更新 GitHub Draft Release。维护者完成人工验收前不应公开 Release。

未签名安装方式及安全注意事项见 [未签名安装说明](docs/installing-unsigned.md)，完整发布步骤见 [发布流程](docs/release-process.md)。请不要为了安装本应用而关闭系统安全机制。

## 项目结构

```text
src/main/       Electron 主进程：生命周期、多窗口管理（伙伴/设置/气泡）、托盘、生活状态、提醒、休息、素材、音频、设置与安全策略
src/preload/    窄类型 IPC 桥接层
src/renderer/   React 桌面伙伴窗口（PetShell）、气泡窗口（BubbleShell）与设置窗口（SettingsShell）
src/shared/     主进程与 Renderer 共用的契约、对白目录、动作物理与纯计算逻辑
resources/      运行时托盘资源
build/          electron-builder 图标与构建资源
scripts/        图标生成和发布 tag 校验脚本
docs/           开发、安装、发布和人工验收文档
```
